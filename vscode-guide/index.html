01

これで、何ができるようになる？

VS Codeは「文章もコードも書ける、無料のメモ帳の進化版」です。ここに Claude Code（Anthropic）と Codex（OpenAI）という2人のAIを住まわせると、はるかさんが日本語で頼むだけで⇩ができます。

  • 「このフォルダに、美容サロンのLPを作って」→ HTML／CSS を書いて、ブラウザで見せてくれる
  • 「このバナー画像を見て、余白と文字の強弱を直して」→ 画像を見て、直し方を返してくれる
  • 「Figma のこのフレームを、そのままコードにして」→ Figma とつないで書き出してくれる
  • 「AIラボの管理画面の文言を変えて、公開して」→ 直して、インターネットに反映までしてくれる

ChatGPT の画面に貼り付けるのと違うのは、AIが『 はるかさんのパソコンの中のファイルを直接さわれる 』こと。だから「作って→直して→公開」が1つの会話で終わります。

02

準備するもの

  • パソコン：Mac（macOS 13 以降）か Windows 10／11。メモリ 4GB 以上
  • Claude の有料プラン（Pro か Max）：Claude Code はこの契約で使えます。無料プランでは使えません
  • ChatGPT の有料プラン（Plus 以上）：Codex はこの契約で使えます。無料でも制限つきで動きます
  • Figma のアカウント：Figma とつなぐときに使います（デザイン用の有料席があると、VS Code の中で Figma を開く拡張機能も使えます）
  • GitHub のアカウント（無料）：作ったページをインターネットに公開するときに使います。あとからでも大丈夫

所要時間の目安：セットアップ 15〜20分＋サインイン 5分。ネット回線が遅いと、ダウンロードにもう少しかかります。

03

貼るだけセットアップ

ここが本題です！！ 下の1行をコピーして、貼って、Enter。あとは自動で ⇩ が全部入ります。

  • VS Code 本体（＋日本語化）
  • Claude Code と Codex（それぞれ公式の入れ方）
  • デザイナー向けの拡張機能 12個（05 で説明）
  • デスクトップに「AIラボ」フォルダ（作業場所）
  • Claude Code と Figma の接続（公式の Figma MCP）
1
「ターミナル」を開く

キーボードの ⌘（コマンド）＋スペース を押して、「ターミナル」と打って Enter。黒か白の四角い画面が出ます。

そのまま 04 のサインインへ🙌

ダブルクリック派の方は setup-windows.bat をダウンロード → ダブルクリック。「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」。

手動でやりたい人へ自動が不安なときは、この順番で1つずつ。全部「ダウンロード→インストール→次へ」だけです。

  • VS Code を入れる → 開く
  • 左の「四角が4つ」のアイコン（拡張機能）→ 検索欄に Japanese → 「Japanese Language Pack」を Install → 日本語になります
  • 同じ検索欄で Claude Code（発行元 Anthropic）→ Install
  • 同じ検索欄で ChatGPT（発行元 OpenAI。これが Codex です）→ Install
  • 05 の拡張機能を、同じやり方で好きなだけ

05

デザイナー向けセット（拡張機能）

貼るだけセットアップで、まとめて入っています。「これ何？」を1行ずつ⇩

Claude Codeanthropic.claude-codeAnthropic の AI。ファイルを作る・直す・公開までやってくれる相棒
ChatGPT（Codex）openai.chatgptOpenAI の AI。同じことができるもう1人。得意分野が少し違うので2人いると心強い
Japanese Language PackMS-CEINTL.vscode-language-pack-jaVS Code のメニューを日本語に
Figma for VS Codefigma.figma-vscode-extensionVS Code の中で Figma のデザインを開いて、色や余白の値を見られる（Figma の有料席が必要）
Live Serverritwickdey.LiveServer作った HTML をブラウザで即プレビュー。直すと自動で更新
Prettieresbenp.prettier-vscodeコードの見た目を自動で整える（インデントのズレを直してくれる）
Auto Rename Tagformulahendry.auto-rename-tagHTML のタグを片方直すと、閉じタグも一緒に直る
Color Highlightnaumovs.color-highlight#a75da9 のような色コードに、その色が表示される
Image previewkisstkondoros.vscode-gutter-preview画像のファイル名にマウスを乗せると、画像が見える
Material Icon ThemePKief.material-icon-themeファイルの種類がアイコンで分かる（見た目がかわいくなる）
HTML CSS Supportecmel.vscode-html-cssclass 名を打つと候補が出る
Path Intellisensechristian-kohler.path-intellisense画像やファイルの場所を打つと候補が出る（打ち間違いが減る）

あとから入れたいときは：左の「四角が4つ」のアイコン → 検索欄に上の名前 → Install。

06

Figma とつなぐ

Claude Code に「Figma のこのフレームを見て」と頼めるようにする設定です。貼るだけセットアップで済んでいますが、あとから入れるときは⇩

claude mcp add --transport http figma https://mcp.figma.com/mcp

ターミナル（Windows は PowerShell）に貼って Enter。初めて使うときに Figma のログイン画面が出るので「許可」します。

使い方Figma でフレームを選んで、右クリック →「Copy link to selection」。そのリンクを Claude Code に貼って「これを HTML と CSS にして」と頼むだけ✨

Figma 公式の「Figma MCP」を使っています。Figma の全プラン・全席で使えます（VS Code の中で Figma を開く拡張機能とは別物です）。

07

最初にやってみること（3つ）

VS Code の上メニュー「ファイル」→「フォルダーを開く」→ デスクトップの「AIラボ」を開いてから、Claude Code のチャット欄に⇩を貼ってみてください。

① ページを作ってもらう「美容サロンの LP を1枚作ってください。ファーストビュー・お悩み・メニュー・料金・アクセス・予約ボタンの順で。色はベージュとゴールド、フォントは游ゴシック。作ったらブラウザで開いて見せてください」
② 画像を見て添削してもらう「AIラボ」フォルダにバナー画像を入れて → 「このバナーを、余白・文字の強弱・配色・揃え・CTA の順で見て、直すところを教えてください」
③ Figma からコードにしてもらうFigma のフレームのリンクを貼って → 「このデザインをそのまま HTML と CSS にしてください。スマホ幅でも崩れないように」

コツは『 誰向け・何のため・どんな順番 』を先に書くこと。カルテの書き方と同じです🤍 途中で「ここ違う」と言えば、何回でも直してくれます。

08

困ったときは

「command not found」「claude は認識されていません」と出る

ターミナル（PowerShell）を一度閉じて、開き直してからもう一度。それでもダメなら、03 の1行をもう一度貼ります（2回やっても壊れません）。

Mac で「開発元を確認できないため開けません」

ファイルを右クリック →「開く」→「開く」。初回だけです。

Windows で「スクリプトの実行が無効」と出る

PowerShell に Set-ExecutionPolicy -Scope CurrentUser RemoteSigned と貼って Enter → もう一度 03 の1行。

サインインしても「Sign in」に戻る

Claude の無料プランでは Claude Code が使えません。Pro／Max に変えてから、チャット欄に /login。

いまの状態を点検したい

ターミナルで claude doctor と打つと、入っているか・設定が正しいかを教えてくれます。

それでも困ったら

ターミナルの画面をスクショして、くみこに送ってください。エラーは全部「次の一歩が分かる情報」なので、怖くないです🙌

用語ミニ辞典

ターミナル：文字で命令する画面。「貼って Enter」だけできれば十分
拡張機能：VS Code に足す機能。スマホのアプリと同じ感覚
MCP：AI と他のアプリ（Figma など）をつなぐ差し込み口
リポジトリ：GitHub に置くフォルダ。公開ページの元
push（プッシュ）：作ったものをインターネットに反映する操作
Homebrew／winget：アプリをまとめて入れてくれる道具。裏で動くだけ
