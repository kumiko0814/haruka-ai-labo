Claudeが使えなくても大丈夫です

運用は3つのレベルに分かれています

「AIを使いこなさないと運用できない」というものではありません。日々のことのほとんどは管理画面の操作だけで完結します。Claude（AIチャット）を使うのは、数ヶ月に一度あるかどうかの場面だけです。

レベル0

毎日〜毎週の運用

Claude不要・管理画面だけ
  • 受講生の招待リンク発行
  • カルテ受信ボックスの確認と返信
  • 進捗・傾向の確認
  • みんなへのメッセージ更新
  • バグ報告の確認
  • 週1回は必ず管理画面を開く（Supabase無料プランは1週間アクセスがないと自動的に止まってしまうため）
レベル1

募集期ごとの更新

Claude不要・ファイルを1つ編集
  • 受講料の変更
  • 締切日の変更
  • 開講日の変更
  • 週ごとの日程の変更
  • お申込みリンクの変更
  • 第2期への切替
レベル2

数ヶ月に1回の変更

Claudeに頼むと楽にできます
  • AIはるかの回答を増やす・直す（ai.htmlのRULES）
  • LPの文章やデザインの変更
  • 講師プロフィールの変更（lp.htmlのナビゲーター欄）
  • キャラクター画像の差し替え（assetsフォルダ）
3

毎日の運用 手順

レベル0・管理者ボードだけでできます

管理者ボードのデモ画面を開きながら読み進めていただくとわかりやすいです。

1
受講生の招待リンクを発行する「参加者の招待」に名前を入れて発行ボタンを押すと、その方専用のURLができます。LINEやメールでご本人に送ってください。
2
カルテ受信ボックスを確認して返信する届いた内容を読み、返信欄にアドバイスを書いて送信ボタンを押します。送った内容は、その方の「AIカルテ」画面に「はるかからのアドバイス」として自動で届きます。
3
進捗・傾向を確認する「カリキュラムの進捗」「みんなの傾向」で、全体の状況をひと目で確認できます。
4
みんなへのメッセージを更新する「みんなへのメッセージ」の欄を書き換えて保存すると、参加者全員の画面に表示されます。開講のごあいさつや、その週のひとことにご利用ください。
5
バグ報告を確認する「バグ報告」に届いた内容を確認し、必要であれば対応します。
6
週1回は必ず管理画面を開く無料のデータベース（Supabase）は、1週間まったくアクセスがないと自動的に停止してしまいます。曜日を決めて、週に1回はこのページを開く習慣をつけてください。
4

募集期の更新 手順

レベル1・labo_config.js を1つ編集するだけ

labo_config.js は、ラボ名・受講料・締切・お申込みリンクなど、各ページに表示される文字を1か所にまとめた設定ファイルです。この中の値を書き換えて保存するだけで、ご案内ページ・AIはるか・カルテ・管理画面の表示がまとめて変わります。

var LABO_CONFIG = {
  labo_name: "AI活用ラボ",
  company: "合同会社Li-Li",
  instructor_name: "菅野 春香",
  instructor_nick: "はるか",
  instructor_title: "合同会社Li-Li 代表・lilisコンサル 主宰",
  ai_name: "AIはるか",
  term_label: "第1期",
  target: "lilisコンサル 受講生・卒業生 限定",
  price: "45,000円",
  price_badge: "第1期 特別価格｜受講生・卒業生 限定",
  price_note: "第2期以降の一般募集では58,000円（税込）を予定しています。第1期は特別価格でご案内します。",
  payment: "クレジットカード決済（分割のご相談も可能）／銀行振込",
  start_date: "2026年10月上旬（予定・詳細日程は調整中）",
  deadline: "2026年9月15日（火）",
  archive_note: "毎回の勉強会はアーカイブ（録画）が残るので、当日参加できなくても後から視聴できます。",
  apply_url: "https://univa.cc/zgpD3J",
  apply_label: "クレジットカードで申し込む",
  tokutei_url: "https://www.lilisconsul.com/tokutei",
  weeks: ["日程調整中","日程調整中","日程調整中","日程調整中","日程調整中","日程調整中"]
};

①　github.com を開き、このリポジトリを開きます。

②　ファイル一覧から labo_config.js をクリックします。

③　右上の鉛筆マーク（Edit）を押します。

④　" "（引用符）の中の文字だけ書き換えます。前後の記号や ,（カンマ）は消さないでください。

⑤　右上の緑色のボタン「Commit changes」を押し、出てきた画面でもう一度「Commit changes」を押します。

⑥　1〜2分待ってからページを再読み込みします。反映されない時は、URLの末尾に ?v=2 を付けて開いてみてください。

つまずきやすいポイントと対処
  • 引用符（" "）ごと消してしまう　→　前後の " " は残したまま、中の文字だけを書き換えてください。
  • 行の最後の ,（カンマ）を消してしまう　→　1行ごとの末尾の , はそのまま残してください（いちばん最後の行だけカンマなしでOKです）。
  • 全角の引用符（" "）になってしまう　→　半角の " のまま書き換えてください。日本語入力中に変換されて全角になっていないか、保存前にご確認ください。

第2期に切り替える時は、主に次の項目を書き換えます。

term_label     "第1期"        →  "第2期"
price          "45,000円"     →  新しい受講料
price_badge    "第1期 特別価格｜受講生・卒業生 限定"  →  次期の案内文
price_note     一般募集の告知に合わせて書き換え（不要なら空文字 "" でも可）
target         "lilisコンサル 受講生・卒業生 限定"  →  次期の対象者
deadline       "2026年9月15日（火）"  →  新しい締切日
weeks          日程が決まった週から、順番に書き換え

Claudeに頼むとき

レベル2・数ヶ月に1回

claude.ai を開き、該当するファイル（例：ai.html）をチャット画面にドラッグ＆ドロップまたは添付してから、下のプロンプトの〇〇や『　』の中をご自身の内容に書き換えて、そのまま貼って送信してください。

① AIはるかの回答を追加する

添付するファイル：ai.html／あわせて人格設計資料（Googleドキュメント）も貼るとより精度が上がります。
添付するai.htmlのRULES配列に、新しい質問と回答を1件追加してください。

追加したい相談内容：
『（ここに追加したい質問を書いてください。例：オープンチャットに入れない時はどうすればいいですか）』

条件：
・はるかさんの口調（☺️や✨を使った、やわらかい話し方）で、3つの吹き出しに分けて回答してください
・RULES配列の他の項目とまったく同じ書き方（re: 正規表現, replies: [[...]] の形）に合わせてください
・「必ず」「絶対に」など、保証をするような言い方は避けてください
・書き換えたファイル全体を返してください

② LPの文章を直す

添付するファイル：lp.html
添付するlp.htmlの中の、〇〇の文章を直してください。

直したい内容：
『（ここに直したい箇所と、どう直したいかを書いてください。例：受講料の説明をもっと簡潔にしたい）』

条件：
・すでにあるデザイン（色・フォント・レイアウト）はそのまま変えないでください
・文章のトーンは、やわらかい敬体（です・ます）のままにしてください
・書き換えたファイル全体を返してください

③ 表示が崩れた・動かない時の修正依頼

添付するファイル：症状が出ているファイル（例：index.html）
添付するファイル（〇〇.html）で、下記の不具合が起きています。原因を調べて直してください。

起きていること：
『（ここに症状を書いてください。例：スマホで見るとボタンがはみ出す／申し込みボタンを押しても反応しない）』

環境：
・スマートフォン／パソコンのどちらか（わかれば機種やブラウザも）

条件：
・デザインや他の機能は変えず、不具合の原因だけを直してください
・直した箇所と理由を、最後に簡単に説明してください
・書き換えたファイル全体を返してください

トラブル対応Q&A

Q.画面が表示されません
GitHub Pagesは、ファイルを更新してから反映まで1〜2分ほどかかることがあります。少し待ってから再読み込みしてください。それでも直らない時は、URLのつづりが正しいかをご確認ください。
Q.カルテの内容が管理者ボードに届きません
supabase_config.js を開き、enabled が true になっているかをご確認ください。false のままだと、送信内容が保存されない確認用の状態のままになります。あわせて、Supabaseが停止していないかもご確認ください。
Q.Supabase（データベース）が停止してしまいました
無料プランは、1週間まったくアクセスがないと自動的に停止する仕組みになっています。Supabaseのダッシュボードを開き、「Restore」ボタンを押していただくと数分で元に戻ります。
Q.決済リンクが開かない・エラーになります
UnivaPay側の決済リンクの設定をご確認ください。あわせて、labo_config.js の apply_url が正しいリンクになっているかもご確認ください。
Q.受講生の方が、自分の専用ページに戻れなくなりました
カルテ入口のページに、登録した時と同じメールアドレスをもう一度入力していただいてください。書いた内容がそのまま残った、同じ専用ページに戻ることができます。

別の会社で使うとき

複製手順の要約

①　リポジトリを複製します（GitHubの「Fork」を使うか、zipでダウンロードして新しいリポジトリにアップロードします）。

②　labo_config.js のブランド項目（ラボ名・会社名・講師名・受講料など）をすべて書き換えます。

③　キャラクター画像（assets/hk-*.png）を、その会社のキャラクターに差し替えます。

④　AIの人格（ai.html の RULES）を、その会社の講師の人格設計資料をもとに書き直します（Claudeに依頼するとスムーズです）。

⑤　新しくSupabase（無料のデータベース）を作り、supabase_config.js を本番用に書き換えます（setup.htmlの手順のとおりです）。

⑥　GitHub Pagesを有効にして公開します。

くわしい手順は、初期設定ガイドをご覧ください。
