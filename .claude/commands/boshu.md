---
description: 募集の設定を変えて公開する（価格・締切・開講日・週の日程・申込リンク）
argument-hint: 例）第2期 10月6日開講 58,000円 締切9月28日
---

あなたはこのラボの運用アシスタントです（ルールは CLAUDE.md）。運営者から募集設定の変更を頼まれました。

運営者の指示: $ARGUMENTS

## 手順

1. `labo_config.js` を読み、いまの値を把握する
2. 指示から変更する項目を決める。対応表：
   - 「第◯期」→ `term_label`、`price_badge`、`price_note` の期の表記
   - 「◯円」→ `price`（税込表記は画面側にあるので数字と「円」だけ。例 `58,000円`）
   - 「締切◯月◯日」→ `deadline`（必ず曜日を付ける。例 `2026年9月28日（月）`）
   - 「◯月◯日開講」「開講◯月」→ `start_date`（具体日が決まっていれば曜日付き、未定なら「（予定・詳細日程は調整中）」を残す）
   - 「第1週は◯日、第2週は…」→ `weeks` の各要素（曜日付き）
   - 「申込リンク」「決済リンク」→ `apply_url`
   - 「対象」「限定」→ `target`、`price_badge`
   - 「支払い方法」→ `payment`
   - 「一般募集」「特別価格」の文言→ `price_note`
3. 指示に無い項目は**変えない**。値以外（`"` や `,` や項目名）は絶対に崩さない
4. 日付は `date -d` または計算で曜日を検算し、指示の年がなければ今年（過去日になる場合は翌年）として運営者に一言確認する
5. 変更前→変更後を表にして見せ、「この内容で公開してよいですか？」と聞く
6. 「OK」をもらったら `labo_config.js` を編集 → `node --check labo_config.js` で壊れていないことを確認 → `git add -A && git commit -m "募集設定を更新：（要約）"` → `git push`
7. 1〜2分待って `curl -s <公開URL>/labo_config.js?v=<乱数>` で新しい値が出ていることを確認
8. 報告：「反映しました。確認用：<公開URL>/lp.html?v=<乱数>」＋変更点の要約

## 注意
- 「第2期に切り替えたい」と言われたら、`term_label` / `price` / `price_badge` / `price_note` / `target` / `deadline` / `start_date` / `weeks` をまとめて確認し、決まっていない項目は「いまは変えずに残します」と伝える
- 期が変わる時、`price_note` の「第2期以降の一般募集では…」の文はそのままだと矛盾する。新しい期に合う一文に書き換える案を出す（例：第2期なら「一般募集価格です。分割のご相談も可能です。」）
- `ai.html` の自動応答（AIチャット）は `labo_config.js` を読んで答えるので、別途直す必要はない
