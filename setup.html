AIカルテ 初期設定（1回だけ）

Re:alizeと同じSupabaseに、カルテ用の入れ物を2つ作ります。作業は「SQLを貼って実行」の1回だけです。

STEP 1　自分のSupabase（無料）を作る

① supabase.com でアカウント作成（GitHubかメールで1分）
② 「New project」でプロジェクトを1つ作る（名前は自由・リージョンはTokyo・無料プランでOK）
③ できたら左メニューの「SQL Editor」→「New query」を開く

STEP 2　下のSQLをコピーして貼り付け、「Run」を押す

create table if not exists ailab_notes (
  id bigserial primary key,
  member_id text not null,
  member_name text,
  mood text,
  worry text,
  want text,
  created_at timestamptz default now()
);
create table if not exists ailab_advice (
  id bigserial primary key,
  target_id text not null,
  author_name text default 'はるか',
  message text,
  created_at timestamptz default now()
);
alter table ailab_notes enable row level security;
alter table ailab_advice enable row level security;
drop policy if exists ailab_notes_all on ailab_notes;
create policy ailab_notes_all on ailab_notes
  for all to anon using (true) with check (true);
drop policy if exists ailab_advice_all on ailab_advice;
create policy ailab_advice_all on ailab_advice
  for all to anon using (true) with check (true);

STEP 3　接続テスト

Runが終わったら、このボタンを押してください。

STEP 3.5　接続情報をサイトに書き込む

Supabaseの左メニュー「Settings」→「API」を開き、Project URL と anon（publishable）キー をコピーします。
このサイトのファイル supabase_config.js を開いて、URLとキーを貼り付け、enabled を true にして保存してください。これで全ページが本番モードになります（それまでは安全なデモモードです）。

STEP 4　データ保護（削除ブロック・1回だけ／おすすめ）

このSQLを実行すると、サイトで使っている公開キーからはデータを消すことが不可能になります（書く・読む・返信はこれまで通り）。消せるのはSupabase管理画面を開けるはるかだけになります。

drop policy if exists ailab_notes_all on ailab_notes;
drop policy if exists ailab_advice_all on ailab_advice;
drop policy if exists ailab_notes_sel on ailab_notes;
drop policy if exists ailab_notes_ins on ailab_notes;
drop policy if exists ailab_notes_upd on ailab_notes;
drop policy if exists ailab_advice_sel on ailab_advice;
drop policy if exists ailab_advice_ins on ailab_advice;
create policy ailab_notes_sel on ailab_notes
  for select to anon using (true);
create policy ailab_notes_ins on ailab_notes
  for insert to anon with check (true);
create policy ailab_notes_upd on ailab_notes
  for update to anon using (true) with check (true);
create policy ailab_advice_sel on ailab_advice
  for select to anon using (true);
create policy ailab_advice_ins on ailab_advice
  for insert to anon with check (true);
