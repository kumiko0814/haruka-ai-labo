# AI活用ラボ OEMパッケージ（はるか版）

「AIカルテ」を中心にした受講生サポートシステム一式です。すべて無料インフラ（GitHub Pages＋Supabase無料プラン）で動きます。

## 構成
| ファイル | 役割 |
|---|---|
| lp.html | ご案内LP（価格・日程などは【 】を書き換え） |
| start.html | 参加者の入口。名前＋メールで専用ページを自動発行 |
| index.html | 参加者マイページ（カルテ・アドバイス・カリキュラム・分析・AIはるか） |
| ai.html | AIはるか（24時間の自動おへんじ。回答はRULESに追加自由） |
| kanri.html | 管理者ボード（受信箱・下書き承認・進捗グラフ・一斉メッセージ） |
| setup.html | 設置ガイド（Supabase作成→SQL→接続設定） |
| supabase_config.js | 接続設定（enabled:true にするまで全ページ安全なデモモード） |
| assets/ | キャラクター素材5点（差し替え可能） |

## はじめかた
1. setup.html を開いて、書いてある順にすすめる（10分）
2. supabase_config.js に接続情報を書いて enabled:true
3. 【 】になっている箇所（価格・日程・プロフィール等）を書き換える
4. GitHub Pages などで公開

デモの見かた：各ページに `?demo=1` を付けるとサンプルデータで動きます。
