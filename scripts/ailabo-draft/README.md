# カルテ自動下書き（scripts/ailabo-draft）

受講生のカルテに、講師本人の文体で「下書き」を自動で入れる仕組みです。
運営者は管理者ボードで下書きを読み、「承認して送信」を押すだけ。**確認なしに受講生へ届くことはありません。**

## 流れ

```
受講生がカルテを送る
   ↓（2時間おき・自動）
pending.py  … 未返信のカルテを集める（返信済み・下書き済み・バグ報告などは除外）
   ↓
Claude      … 人格資料（persona/）の文体で下書きを書く
   ↓
post.py     … author_name="draft" で保存（安全装置つき）
   ↓
管理者ボード … 返信欄に「AI下書き（編集できます）」として自動表示 → 直して「承認して送信」
   ↓
受講生の画面に「講師からのアドバイス」として届く／下書きは draft_used に切り替わる
```

## ファイル

| ファイル | 役割 |
|---|---|
| `labo_env.py` | `supabase_config.js` と `labo_config.js` から接続情報・講師名を読む共通部品（コードに埋め込まない） |
| `pending.py` | 未返信カルテ＋講師の返信コーパス＋編集差分（下書き→送信文）を出力。`--json 出力先` で機械可読にも保存 |
| `post.py` | `drafts.json` を下書きとして投入。承認待ちがある相手には二重投入しない。保証表現・設定NG語を含むと中止 |
| `ROUTINE.md` | クラウド定期ジョブ（Claude Code ルーティン）に登録するプロンプト雛形 |

## 動かし方

- **自動（推奨）**：`ROUTINE.md` の手順でルーティンを登録。以後は何もしなくてよい
- **手動**：Claude Code でこのフォルダを開き `/karte` または「下書き作って」と話しかける（同じ処理をその場で1回実行）

## 別の会社で使うとき

コードの変更は不要です。`supabase_config.js`（接続先）と `labo_config.js`（講師の呼び名 `instructor_nick`）を書き換え、人格資料を `persona/` に置き、`ROUTINE.md` に沿って登録し直すだけで動きます。
`labo_config.js` に `draft_ng_words: ["使ってはいけない語", ...]` を足すと、その語を含む下書きは投入前に止まります。

## 安全装置

- デモモード（`enabled:false`）では一切動かない
- 下書きは必ず `author_name="draft"`。講師名で投入することはない
- 「絶対〜できます」「必ず〜万円」「保証します」を含む下書きは投入しない
- 危機ワード（死にたい 等）を含むカルテは下書きを作らず、本人対応を促す
- `ailab_notes`（カルテ本体）は書き換えない
