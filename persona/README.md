# persona フォルダについて

このフォルダには、講師本人の「人格設計資料」を置きます。
Claude はここにある資料を読んで、告知文やカルテ返信を講師本人の文体で作ります。

## 置くファイル

- `persona_haruka.md` … AI春香 人格設計資料 v4（引き継ぎ時にファイルで受け取ってください）

## 大事なこと

- このフォルダの中身は `.gitignore` で **GitHub には上がらない** 設定になっています（講師本人の経歴や家族の情報が含まれるため）
- `README.md` だけは GitHub に上がります（このフォルダの説明用）
- 別の会社・別の講師で使うときは、同じ形式でその講師の資料を `persona_〇〇.md` として置き、`CLAUDE.md` の「人格資料」の行をそのファイル名に書き換えてください

## ファイルが無いとどうなるか

Claude に `/karte` や `/kokuchi` を頼んだとき、「persona フォルダに人格資料がありません」と案内されます。
資料を置けばすぐ使えるようになります。
