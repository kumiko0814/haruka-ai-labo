運用は「承認して送信」だけ

3つのレベルに分かれています

毎日のお仕事は、管理者ボードを開いて下書きを読み、「承認して送信」を押すことです。それ以外の変更が必要になった時だけ、Meroneに頼むか、Claude Codeという道具を使います。むずかしい操作を覚えていただく必要はありません。

レベル0

毎日の運用

管理者ボードだけ・Claude不要
  • 管理者ボード（ブラウザで開き、合言葉でログインします）を開きます
  • 「カルテ受信ボックス」を開き、返信欄に自動で入っている下書きを読みます
  • そのまま送ってよければそのまま、直したいところがあれば直してから、「承認して送信」を押します。押すまでは受講生に届きません
  • 招待リンクの発行、進捗の確認、バグ報告の確認も、同じ管理者ボードで行えます
  • 週1回は必ず管理者ボードを開いてください（Supabaseの無料プランは、1週間まったくアクセスがないと自動で休止する仕組みのためです）
レベル1

募集期ごとの更新

価格・締切・日程の変更
  • やりやすい方法を、次の3つからお選びください
  • ①　Meroneに「第2期の価格と締切を変えてほしい」と頼む
  • ②　Claude Codeをお使いなら、/boshuと話しかける（例：「第2期 10月6日開講 58,000円 締切9月28日」）
  • ③　GitHub（このシステム一式を保管している場所）をブラウザで開き、labo_config.jsを直接編集する
レベル2

数ヶ月に1回の変更

告知文・LP修正・AI回答の追加
  • 「告知文がほしい」「LPの文章を直して」「AIチャットの回答を増やして」
  • Meroneに頼むか、Claude Codeで話しかけるか、やりやすい方をお選びください
  • 講師プロフィールやキャラクター画像の差し替えも、同じように頼めます
Claudeが使えない時はこのページの後ろにある「Claude Codeが使えない時だけ」の章に、代わりの手順をまとめてあります。ふだんはここまで読んでいただければ十分です。

自動で動いているもの

運営者が何もしなくても動く3つの仕組み

裏側では、次の3つが自動で動いています。仕組みを覚えていただく必要はありませんが、止まった時に気づけるよう、簡単にご紹介します。

①

カルテ下書きの自動作成

2時間おき（毎日7:40〜21:40・1日8回）
受講生→ pending→ Claude→ 下書き→ 承認して送信→ 受講生

止まると、管理者ボードに新しい下書きが増えなくなります。数日たっても下書きが出ない時や、/checkの報告で気づけます。気づいたらMeroneまでご連絡ください。

②

バグ報告の自動修正パトロール

毎時

止まると、送っていただいた不具合がそのまま直らずに残ります。同じ不具合が何時間も直らない時に気づけます。気づいたらMeroneまでご連絡ください。

③

データの自動バックアップ

毎朝・Merone側

止まると、万一の時に復元できるデータが古いままになります。この作業はMerone側の仕組みで行っているため、運営者が気づく必要はありません。気になる時はMeroneまでご確認ください。

4

Claude Codeを使いたい場合（任意）

使う場合だけ、ここの準備が必要です

Claude Codeは、Claudeにファイルの読み書きや公開作業までお願いできるアプリです。無くても運営はここまでの仕組みで回りますが、募集条件の変更や告知文づくりを自分の言葉で頼みたい時に使える道具です。最初の準備さえ済めば、以降は日本語で話しかけるだけになります。

①　Anthropic（Claudeを作っている会社）のアカウントを作り、Claude Pro以上のプラン（Claude Codeが使えるプラン）にご登録ください。

②　Claude Code（パソコンにインストールするアプリ、またはVS Codeという編集ソフトの拡張機能）をインストールしてください。

③　GitHub（このシステム一式を保管している場所）のアカウントでログインします。初回だけの操作で、ブラウザの画面で「許可」ボタンを押していただくだけです。手順はClaudeが画面に沿ってご案内します。

④　このリポジトリ（このシステム一式が入ったフォルダのことです）を、Claude Codeで開きます。まだお手元にフォルダが無い場合は、複製の方法を初期設定ガイド（setup.html）でご案内しています。

⑤　引き継ぎの際にお渡しした人格設計資料のファイルを、personaという名前のフォルダに入れてください（このファイルはGitHub上には公開されない仕組みになっています）。

⑥　/check と入力して送信し、「表示OK」という報告が出れば、準備は完了です。

費用の目安 Claude Proは月額制のご利用料金です。詳しい金額はAnthropicの料金ページでご確認ください。それ以外に追加でかかる費用はありません（SupabaseとGitHub Pagesは、どちらも無料の範囲でご利用いただけます）。

6

カルテ返信の品質について

安心してお使いいただくために
  • 下書きは、2時間おきの自動ルーティンで作っても、/karteで今すぐ作っても、人格設計資料の「返信文体の6つの手順」と、講師ご本人が書かれた模範回答3本を基準に作られます。
  • 講師が下書きを直して送ると、その直し方が次回から学習され、同じような直しを先回りして反映するようになります。数件直していただくうちに、だんだんご本人らしい文体に近づいていきます。
  • どんな下書きも、必ずあなたが読んで「承認して送信」を押したあとに届きます。確認なしで受講生に届くことはありません。
  • 「死にたい」「消えたい」など心配な内容の相談は、自動では下書きを作らず、管理者ボードに「本人対応」としてお知らせします。運営者ご本人から、直接声をかけてください。
  • 医療・法律・投資について断定的な言い方をしたり、収入を保証するような表現をすることはありません。

Claude Codeが使えない時だけ

予備の手順です・ふだんは不要です

通常はここを読んでいただく必要はありません。Claude Codeが使えない状況になった時のための、予備の手順です。

予備手順①　募集期の更新をブラウザだけで行う

labo_config.js は、ラボ名・受講料・締切・お申込みリンクなど、各ページに表示される文字を1か所にまとめた設定ファイルです。この中の値を書き換えて保存するだけで、ご案内ページ・AIはるか・カルテ・管理画面の表示がまとめて変わります。

var LABO_CONFIG = {
  labo_name: "AI活用ラボ",
  company: "合同会社Li-Li",
  instructor_name: "菅野 春香",
  instructor_nick: "はるか",
  instructor_title: "合同会社Li-Li 代表・lilisコンサル 主宰",
  ai_name: "AIはるか",
  term_label: "第1期",
  target: "lilisコンサル 受講生・卒業生 限定",
  price: "45,000円",
  price_badge: "第1期 特別価格｜受講生・卒業生 限定",
  price_note: "第2期以降の一般募集では58,000円（税込）を予定しています。第1期は特別価格でご案内します。",
  payment: "クレジットカード決済（分割のご相談も可能）／銀行振込",
  start_date: "2026年10月上旬（予定・詳細日程は調整中）",
  deadline: "2026年9月15日（火）",
  archive_note: "毎回の勉強会はアーカイブ（録画）が残るので、当日参加できなくても後から視聴できます。",
  apply_url: "https://univa.cc/zgpD3J",
  apply_label: "クレジットカードで申し込む",
  tokutei_url: "https://www.lilisconsul.com/tokutei",
  weeks: ["日程調整中","日程調整中","日程調整中","日程調整中","日程調整中","日程調整中"]
};

①　github.com を開き、このリポジトリを開きます。

②　ファイル一覧から labo_config.js をクリックします。

③　右上の鉛筆マーク（Edit）を押します。

④　" "（引用符）の中の文字だけ書き換えます。前後の記号や ,（カンマ）は消さないでください。

⑤　右上の緑色のボタン「Commit changes」を押し、出てきた画面でもう一度「Commit changes」を押します。これが push（インターネットに公開する操作）にあたります。

⑥　1〜2分待ってからページを再読み込みします。反映されない時は、URLの末尾に ?v=2 を付けて開いてみてください。

つまずきやすいポイントと対処
  • 引用符（" "）ごと消してしまう　→　前後の " " は残したまま、中の文字だけを書き換えてください。
  • 行の最後の ,（カンマ）を消してしまう　→　1行ごとの末尾の , はそのまま残してください（いちばん最後の行だけカンマなしでOKです）。
  • 全角の引用符（" "）になってしまう　→　半角の " のまま書き換えてください。日本語入力中に変換されて全角になっていないか、保存前にご確認ください。

第2期に切り替える時は、主に次の項目を書き換えます。

term_label     "第1期"        →  "第2期"
price          "45,000円"     →  新しい受講料
price_badge    "第1期 特別価格｜受講生・卒業生 限定"  →  次期の案内文
price_note     一般募集の告知に合わせて書き換え（不要なら空文字 "" でも可）
target         "lilisコンサル 受講生・卒業生 限定"  →  次期の対象者
deadline       "2026年9月15日（火）"  →  新しい締切日
weeks          日程が決まった週から、順番に書き換え

トラブル対応Q&A

Q.管理者ボードを開いたら「合言葉」を聞かれました
本番の管理者ボードは、運営者だけが開けるように合言葉で守られています（受講生の相談内容が入っているためです）。合言葉は引き継ぎの時に個別にお伝えします。一度入れれば、そのブラウザでは次回から聞かれません。別のスマホやパソコンで開く時は、もう一度入力してください。合言葉を変えたい時は、Claudeに「管理者ボードの合言葉を〇〇に変えて」と話しかけるだけで変更できます（変えた後は、全員がもう一度入力する形になります）。
Q.画面が表示されません
GitHub Pagesは、ファイルを更新してから反映まで1〜2分ほどかかることがあります。少し待ってから再読み込みしてください。それでも直らない時は、URLのつづりが正しいかをご確認ください。
Q.カルテの内容が管理者ボードに届きません
supabase_config.js を開き、enabled が true になっているかをご確認ください。false のままだと、送信内容が保存されない確認用の状態のままになります。あわせて、Supabaseが休止していないかもご確認ください。
Q.下書きが入っていません
下書きは2時間おき（毎日7:40〜21:40）にしか作られないので、まずは少し待ってみてください。それでも入らない時は、本番化されているか（supabase_config.jsのenabled）、Supabaseが休止していないか、自動下書きルーティンが登録されているかの順にご確認ください。それでも解決しない時はMeroneまでご連絡ください。
Q.下書きが自分らしくありません
そのまま直して「承認して送信」を押してください。直していただいた内容は次回から学習され、以降の下書きに反映されます。数件直していただくうちに、だんだんご本人らしい文体に近づいていきます。
Q.Supabase（データベース）が休止してしまいました
無料プランは、1週間まったくアクセスがないと自動的に休止する仕組みになっています。Supabaseのダッシュボードを開き、「Restore」ボタンを押していただくと数分で元に戻ります。心配な時は /check と話しかけていただければ、状態を確認してお伝えします。
Q.決済リンクが開かない・エラーになります
UnivaPay側の決済リンクの設定をご確認ください。あわせて、labo_config.js の apply_url が正しいリンクになっているかもご確認ください。
Q.受講生の方が、自分の専用ページに戻れなくなりました
カルテ入口のページに、登録した時と同じメールアドレスをもう一度入力していただいてください。書いた内容がそのまま残った、同じ専用ページに戻ることができます。
Q.Claudeが「personaフォルダに資料がありません」と言います
引き継ぎの際にお渡しした人格設計資料のファイルを、personaという名前のフォルダに入れてください。ファイルが無いままでは、Claudeは講師の人格を作り話しにしない仕組みになっています。
Q.push（公開する操作）に失敗しました
GitHub（このシステム一式を保管している場所）への初回ログインがまだの状態です。Claudeの案内どおりに、ブラウザでログインボタンを押してください。一度ログインすれば、次回からは自動で進みます。

複製手順の要約

①　リポジトリを複製します（GitHubの「Fork」を使うか、zipでダウンロードして新しいリポジトリにアップロードします）。

②　labo_config.js のブランド項目（ラボ名・会社名・講師名・受講料など）をすべて書き換えます。

③　キャラクター画像（assets/hk-*.png）を、その会社のキャラクターに差し替えます。

④　AIの人格（ai.html の RULES）を、その会社の講師の人格設計資料をもとに書き直します（Claudeに依頼するとスムーズです）。

⑤　新しくSupabase（無料のデータベース）を作り、supabase_config.js を本番用に書き換えます（setup.htmlの手順のとおりです）。

⑥　GitHub Pagesを有効にして公開します。

くわしい手順は、初期設定ガイドをご覧ください。複製したあとは、Claude Codeで「設置ガイド（setup.html）に沿って進めて」と頼んでいただければ、そのまま案内してくれます。
